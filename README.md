## About

I design, audit, migrate and secure critical infrastructure and cybersecurity platforms through **SamHan**, an independent cybersecurity consultancy based near Nantes.

Main areas of work:

- **F5 BIG-IP**: AWAF / ASM, LTM, APM, DNS, BIG-IQ, iSeries, rSeries, VIPRION
- **Fortinet**: FortiGate, FortiWeb, FortiADC, FortiPAM, FortiAuthenticator, FortiDeceptor, FortiSASE, FortiManager, FortiAnalyzer
- **WALLIX**: Bastion, Session Manager, Access Manager, Trustelem
- **Stormshield**: firewall architecture, migration and audit
- **Rubycat**: architecture, integration, deployment and audit across the product range
- **Reverse proxy / WAF / load balancing**
- **Cybersecurity architecture and technical audits**
- **Email & DNS audits**: SPF, DKIM, DMARC, BIMI, CAA, MX and DNS consistency

My work covers architecture, migration, hardening, exposure and publication flows, privileged access, segmentation, logging, operational security and technical remediation.
